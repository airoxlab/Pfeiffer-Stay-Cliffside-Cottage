# Cliffside Cottage — Pfeiffer Stay Co. LLC

Single-page website for Cliffside Cottage, a 1,920 sq ft split-level vacation rental in the Walnut Hills neighborhood of Mansfield, Ohio — hot tub, full-size pool table, foosball, cornhole, and 45+ board games. Minutes from Mohican, Malabar Farm, Mid-Ohio, The Ohio State Reformatory, and Snow Trails.

- **Address:** 561 Cliffside Dr, Mansfield, OH 44904
- **Phone:** +1 419-544-0969 (hosts on call 24/7)

## Structure

- `index.html` — the complete site (self-contained CSS, no build step)
- `img/` — cottage photos from the Pfeiffer Stay Co. business profile on Google
- `screenshots/` — per-section screenshots of the rendered site

Open `index.html` in a browser, or deploy the folder as-is to any static host (GitHub Pages, Netlify, etc.).
